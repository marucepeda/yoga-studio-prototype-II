# Yoga Studio — Brand Design Skill

## 1. Brand Identity

Yoga Studio is a digital management tool for a small yoga studio.

Its visual identity should communicate:

- Calmness.
- Balance.
- Simplicity.
- Warmth.
- Trust.
- Clarity.

The application should feel welcoming and human, not commercial or overly technical.

The design must support everyday tasks without creating unnecessary visual stimulation.

## 2. Design Direction

**Visual concept:** Warm Zen Minimalism with an editorial touch.

Design references:

- Japanese-inspired minimalism.
- Natural materials and earthy tones.
- Contemporary editorial layouts.
- Subtle organic details.
- Clean and functional interfaces.

The design should balance aesthetic character with practical usability.

## 3. Color Palette

Use the following reference palette consistently.

| Role | Color | Hex |
|---|---|---|
| Main background | Warm off-white | #F7F6F2 |
| Secondary background | Light sand | #E8E1D5 |
| Neutral surfaces | Warm beige | #D6CEC0 |
| Soft accent | Sage green | #A5AD9B |
| Primary accent | Muted olive green | #727B68 |
| Primary text | Deep charcoal | #343632 |
| White surfaces | White | #FFFFFF |

### Color Usage

- Use warm off-white as the primary background.
- Use sand and beige for secondary surfaces and subtle separation.
- Use sage and muted olive for accents and meaningful interface states.
- Use charcoal for primary text and strong contrast.
- Maintain sufficient contrast for readability and accessibility.

Do not introduce additional accent colors without a clear functional reason.

## 4. Typography

Typography should be readable, restrained and elegant.

Preferred approach:

- A clean sans-serif typeface for interface elements, navigation, forms and data.
- An optional editorial serif typeface for selected headings or brand expressions.

Guidelines:

- Maintain clear typographic hierarchy.
- Use comfortable line heights.
- Avoid excessively small text.
- Avoid decorative fonts for functional information.
- Keep labels and controls easy to scan.

## 5. Layout and Composition

The interface should feel spacious and organized.

Use:

- Generous whitespace.
- Consistent spacing.
- Clear alignment.
- Simple layouts.
- Restrained borders and shadows.
- Subtle rounded corners where appropriate.

Information should be easy to locate without requiring unnecessary navigation.

Prioritize functional clarity over decorative composition.

## 6. Interface Components

All components must follow the same visual language.

### Buttons

- Clear labels describing the action.
- Muted colors.
- Consistent sizing.
- Distinct primary and secondary actions.
- Visible hover, focus and disabled states.

### Forms

- Simple and clearly labeled fields.
- Visible validation messages.
- Consistent spacing.
- Accessible input sizes.

### Tables and Lists

- Clear column hierarchy.
- Easy-to-scan information.
- Subtle separators.
- Avoid excessive borders and visual clutter.

### Status Indicators

Use restrained visual indicators for:

- Confirmed reservations.
- Available spaces.
- Full classes.
- Waiting-list status.
- Attendance.
- Cancellation.

Status must be communicated through text or icons as well as color.

## 7. User Experience Principles

The application serves both studio administrators and students.

Design decisions must prioritize:

- Ease of use.
- Predictable navigation.
- Clear feedback after actions.
- Visibility of important information.
- Minimal cognitive load.
- Error prevention.

Users should always understand:

- What class they are viewing.
- Whether a space is available.
- Whether their reservation is confirmed.
- Whether they are on a waiting list.
- How many credits they have available.

Never rely on color alone to communicate important information.

## 8. Responsive Design

The interface must work on desktop and mobile devices.

Requirements:

- Adapt layouts to smaller screens.
- Preserve readability.
- Keep primary actions accessible.
- Avoid horizontal scrolling whenever practical.
- Maintain consistent visual hierarchy across screen sizes.

## 9. Avoid

Do not use:

- Typical gym or fitness-platform aesthetics.
- Neon or highly saturated colors.
- Strong gradients.
- Excessive animations.
- Gamification elements.
- Decorative elements that compete with information.
- Unnecessary illustrations or icons.
- Dense dashboards with excessive metrics.
- Inconsistent component styles.

## 10. Design Validation Checklist

Before considering a UI implementation complete, verify:

- [ ] The interface follows the defined color palette.
- [ ] Typography is consistent and readable.
- [ ] Visual hierarchy is clear.
- [ ] Components share a coherent design language.
- [ ] Important actions are easy to identify.
- [ ] Status indicators are understandable without relying only on color.
- [ ] The interface is responsive.
- [ ] No unnecessary visual clutter has been introduced.
- [ ] The design supports the actual workflow of the studio.

The final result should feel calm, functional, warm and coherent.
